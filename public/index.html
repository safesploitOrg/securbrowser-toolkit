Security and compatibility notes

SecurBrowser v2 authenticates its format metadata and encrypted payload. A wrong passphrase or modified v2 file will fail authentication rather than returning untrusted plaintext.

Legacy files created by earlier SecurBrowser versions use PBKDF2-SHA256 with 10,000 iterations and AES-256-CBC. They can still be decrypted, but that format does not provide authenticated integrity. New encryption always uses v2.

Files are currently loaded into browser memory in full. For very large files, use a desktop encryption tool designed for streaming data.
